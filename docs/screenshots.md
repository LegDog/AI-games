# Capturing screenshots

The `screenshot` helpers capture actual GTK application widgets in English,
using fixed human-player moves and no Ollama requests. They produce a
configuration view and a game view for each app, without saving game histories
or changing language preferences.

Build the helpers and run them on a graphical session:

```sh
meson setup four-in-a-row/build-ui four-in-a-row -Dapp=true -Dui_tests=true
meson compile -C four-in-a-row/build-ui
meson setup tic-tac-toe/build-ui tic-tac-toe -Dapp=true -Dui_tests=true
meson compile -C tic-tac-toe/build-ui
four-in-a-row/build-ui/screenshot screenshots
tic-tac-toe/build-ui/screenshot screenshots
```

If the build directories already exist, use `meson setup --reconfigure`.
For a virtual display, prefix each capture with
`GDK_BACKEND=x11 GSK_RENDERER=cairo GTK_A11Y=none xvfb-run -a dbus-run-session --`.
CI captures all four PNG files and uploads an `application-screenshots` artifact.
The output directory is ignored by Git. Review the images, then copy chosen
ones into `docs/images/` and link them from the main README. No preview images
are checked in until they can be generated and visually reviewed.

## Pentalpha

After `make GAME=pentalpha test-ui`, run
`pentalpha/build-ui/screenshot screenshots` under the same virtual-display
environment. It captures configuration, a frozen sliding-piece frame, and a
solved board generated by runtime Search. The helper uses a temporary working
directory and does not append to the user's histories.

## Heptalpha

After `make GAME=heptalpha test-ui`, run
`heptalpha/build-ui/screenshot screenshots` under the virtual-display environment
above. Configuration, a frozen curved-slide frame, and a runtime-generated solved
board are captured as `heptalpha-*.png`. The helper uses a temporary directory
for histories and never appends to the user's attempts.

## Peg Solitaire

After `make GAME=peg-solitaire test-ui`, run `peg-solitaire/build-ui/screenshot screenshots` under the virtual display environment above. It captures configuration, a paused English jump, and a solved triangular board as `peg-solitaire-*.png`.

## Pentalfa Cruzado Circulado

After `make GAME=pentalpha-crossed-circle test-ui`, run `pentalpha-crossed-circle/build-ui/screenshot screenshots` under the virtual display environment above. It captures the empty configuration, a partial board with a paused placement, and a wrapped circular placement as `pentalpha-crossed-circle-*.png`.

The Crossed Circle screenshot helper additionally captures `pentalpha-crossed-circle-gf2-optimum.png`: a runtime Gauss–Jordan plan finishing at 34 pieces, with the unchanged 35-piece target and proof diagnostics visible.

## Reversi

After `make GAME=reversi test-ui`, run `reversi/build-ui/screenshot screenshots` under the virtual display environment above. It captures `reversi-configuration.png`, `reversi-flipping.png` (a paused atomic flip), and `reversi-result.png` (a completed runtime Minimax/MCTS game).

## Hex

After `make GAME=hex test-ui`, run `hex/build-ui/screenshot screenshots` under the virtual display environment above. It captures `hex-configuration.png`, `hex-placement.png` (a paused atomic placement), and `hex-result.png` (a completed runtime Minimax/MCTS game with the winning path outlined).

## Tavli

After `make GAME=tavli test-ui`, run `tavli/build-ui/screenshot screenshots` under the virtual display environment above. It captures all five variant setups, Running checker motion, a Plakoto pinned checker, and a Backgammon cube response. The view always remains Player 1's.

## Sokoban

After `make GAME=sokoban test-ui`, run `sokoban/build-ui/screenshot screenshots`
under the virtual display environment above. It captures setup, a paused atomic
box push and a runtime A* solution as `sokoban-*.png`. Histories are isolated in a
temporary directory.

## Go

After `make GAME=go test-ui`, run `go/build-ui/screenshot screenshots` under
the virtual display environment above. It captures `go-setup.png`,
`go-capture.png` (a paused atomic capture), and `go-result.png` (a scored board
with territory overlay). The helper isolates histories in a temporary directory.
